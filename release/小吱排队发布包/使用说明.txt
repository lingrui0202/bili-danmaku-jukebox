小吱主题 · B 站直播排队工具（Windows 11 + OBS）
==================================================

一、先改直播间号
--------------------------------------------------
用记事本打开同目录的 config.json，把 room_id 改成自己的 B 站直播间号（注意是直播间号，不是 UID）：

{
  "room_id": 31182867,          ← 改成你自己的直播间号
  "keyword": "排队",             ← 入队口令（单个时用这个）
  "keywords": ["排队"],          ← 多个口令写这里，例如 ["排队","报名"]
  "contents": ["通行正义","轨外","高危"],   ← 可打的内容，管理页可改
  "priority_gifts": ["粉丝团灯牌"],
  "port": 8765,                 ← 本地网页端口
  "font_size": 36,              ← OBS 名单初始字号
  "max_rows": 50,               ← 最多显示人数
  "priority_enabled": true,     ← false = 取消插队（灯牌不插队）
  "clear_on_start": true        ← 开播（启动程序）时自动清空上一场队列
}

改完保存（编码保持 UTF-8）。改 config.json 后重新启动程序才生效。
懒得改文件也没关系：管理页里就能改直播间号，不用重启。


二、启动
--------------------------------------------------
双击 start.exe，出现黑色命令行窗口后不要关掉，直播期间一直保持运行。
窗口里会显示当前监听的直播间号、入队口令、以及两个开关的状态。


三、OBS 添加浏览器源
--------------------------------------------------
来源 → 添加「浏览器」→ 地址填：

    http://127.0.0.1:8765/console

面板是固定尺寸的竖版，比例 宽:高 = 2:3，例如 600 × 900、700 × 1050。
排队的人放不下时，名单会自动向上循环滚动（约 28 像素/秒），
面板大小始终不变，不会把画面撑变形。

名单第 1 位会带金色描边，表示「当前进行中」；名字后面带金色小标签的
是观众指定要打的内容。观众名字过长时会自动缩小那一行的字号，
尽量显示完整名字，实在放不下才用省略号。
管理页 http://127.0.0.1:8765/ 不要加到 OBS 里，那是给自己操作用的。


四、管理页（给自己用）
--------------------------------------------------
浏览器打开：http://127.0.0.1:8765/
可以：
· 「下一位」按钮：把队首叫号出队，后面的人自动递补；「已叫号」会 +1
· 手动加人、逐行删除
· 拖动滑块调 OBS 字号
· 未开播时用「本地模拟」按钮试排
· 「直播间」面板里输入新的直播间号（或粘贴直播间链接）点「切换」，
  约 10 秒内自动重连，并写入 config.json，不用重启程序
· 「取消插队」开关：打开后观众送灯牌不再插队、也不记录待用资格
· 「开播自动清空」开关：打开后每次启动程序都会清空队列、待用资格，
  并把「已叫号」计数归零，不会把上一场的人带进新的一场
· 「可打内容」输入框：改「排队，XX」里能识别的内容关键词，
  默认「通行正义 / 轨外 / 高危」，保存后写入 config.json
· 「B 站登录」面板：点「生成二维码」后用手机 B 站 App 扫描，
  确认即登录（可拿到完整昵称，不再显示「你***」），
  登录状态保存在本机 auth.json；「退出登录」回到匿名模式


五、排队规则
--------------------------------------------------
· 观众发「排队」（或你在 config.json 里配的其他口令）→ 排到队尾，同一人不重复入队
  口令匹配会忽略空格和标点，所以「排队！」「 排队 」都算；但「不排队」「我想报名」不算
· 发「排队，轨外」这种格式时，会同时记下要打的内容（金色小标签），
  逗号、空格、冒号等都能当分隔符；内容必须是在「可打内容」里配过的词，
  不在列表里就当没指定（仍然正常入队）
· 已在队列的人送「粉丝团灯牌」→ 直接插到第 1 位（除非开了取消插队）
· 队列存在本机 data\state.json，关掉再开还在（除非开播自动清空）


六、常用命令（管理页或程序窗口里都能输）
--------------------------------------------------
next / 下一位        叫号：队首出队，已叫号 +1
add-小明             手动把「小明」加到队尾
add-小明-3           插到第 3 位
del-3                删除第 3 位，后面自动递补
font-42              把 OBS 字号改成 42px（范围 12–160）
room-1809238853      切换直播间（约 10 秒重连，并写入 config.json）
priority-off         取消插队（灯牌不再插队）
priority-on          恢复插队
autoclear-on/off     开播自动清空 开/关
match-排队！          自检：这条弹幕会不会触发入队
list                 查看当前队列
clear                清空队列（不影响待用灯牌资格）
help                 查看全部命令
test-queue-小明      本地模拟某人发「排队」（不会发到 B 站）
test-gift-小明       本地模拟某人送灯牌


七、改主题配色 / 名单样式
--------------------------------------------------
· 排队框由 static\overlay.css 用 CSS 绘制，不依赖图片素材。
  顶部/底部装饰带、票据主色、玫瑰粉、金色描边都在 :root 的 CSS 变量里。
· 名单左右留白、行配色、胶囊圆角、第 1 位金色高亮等也在该文件的变量与规则里，
  改完刷新 OBS 浏览器源即可看到效果。


八、打包给别人时
--------------------------------------------------
· 把整个文件夹一起复制（不要只复制 exe）：start.exe、zlib1.dll、
  config.json、static\ 都要有。
· 建议先删掉 data 文件夹，避免带上你自己的排队记录。
· 对方拿到后按「一、先改直播间号」改 room_id（或在管理页改），
  再双击 start.exe 即可，不需要安装任何环境。


说明：本程序只在本机 127.0.0.1 上开一个网页服务，不会对外发布。
匿名连接时 B 站可能只给脱敏昵称（例如「你***」），属正常现象；
在管理页「B 站登录」里扫码登录即可拿到完整用户名。
