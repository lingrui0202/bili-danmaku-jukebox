# B站弹幕点歌机 + 直播排队

连接 B站直播间，观众发弹幕「**点歌 歌名**」自动搜歌 → 排队 → 播放；
发弹幕「**排队**」加入互动排队名单，送**粉丝团灯牌**可插队。

**点歌与排队深度融合在同一程序内**：

- 同一条 B站弹幕连接：点歌与排队共用监听，切直播间两边同时生效；
- 同一份 B站扫码登录：登录后观众完整昵称/uid 两个功能都能拿到；
- 同一个服务（8788）、同一个管理控制台（「直播排队」标签页）。

歌曲源可插拔（B站 / QQ音乐 / 酷狗 / 网易云 / 本地 / 演示），支持免费 + 扫码登录双模式，
并能识别平台只给「试听片段」的付费/会员歌曲。

---

## 1. 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（默认 mock 弹幕模式，端口 8788）
python run.py
```

启动后终端会打印页面地址，浏览器打开 **管理控制台** 即可使用：

| 页面 | 地址 | 用途 |
|---|---|---|
| 管理控制台 | http://127.0.0.1:8788/web/console.html | 本地操作全部功能（含「直播排队」标签页） |
| OBS 播放页 | http://127.0.0.1:8788/obs | 放进 OBS 浏览器源，黑胶唱片动画 |
| OBS 歌词页 | http://127.0.0.1:8788/stage | 放进 OBS 浏览器源，滚动歌词（支持透明背景 `?transparent=1`） |
| OBS 排队名单页 | http://127.0.0.1:8788/queue | 放进 OBS 浏览器源，竖版排队面板（透明背景） |

> 根路径 `/` 会自动跳转到管理控制台。
> 关闭启动它的命令行终端，程序会自动退出，不会在后台残留。

## 1.5 直播排队

观众在直播间发弹幕（口令可在 `config.yaml` 的 `live_queue.keywords` 配置，默认「排队」）：

| 行为 | 说明 |
|---|---|
| `排队` | 加入队列末尾；重复发送保持原位置，只更新内容 |
| `排队，轨外` | 入队并记录「要打的内容」（分隔符支持 ，；：、。— 与空格等） |
| 送「粉丝团灯牌」 | 已在队列 → 插队到第 1 位；不在队列 → 记 1 次待用资格，之后发「排队」时消耗并插队 |
| 「取消插队」开关 | 开启后灯牌既不插队也不记资格（控制台可切） |

管理控制台「直播排队」标签页支持：叫号「下一位」、手动加人/移位（`add-名字-位置`）、
删人（`del-序号`）、清空、口令/内容/礼物名配置（热生效）、
OBS 字号与面板/名单透明度调节、「开播自动清空」、本地测试（模拟排队/送礼）。

OBS 名单页特性：竖版 2:3 玻璃面板，头部显示实时排队人数，第 1 位高亮描边，
人数超出时名单无缝循环滚动，后端断开时自动隐藏画面。

## 2. 两种弹幕模式

编辑 `config.yaml` 的 `danmaku.mode`（也可在控制台「直播间」面板切换）：

- **`mock`（默认）**：不连接 B站，用控制台里的「模拟弹幕」输入框注入弹幕，方便调试/演示。
- **`live`**：连接真实 B站直播间。设置 `room_id`（live.bilibili.com/ 后的数字）后启动即可自动监听弹幕。
  可选 `credential_file` 填 B站登录 Cookie JSON，提升风控通过率。

> 切换直播间：`POST /api/danmaku/reconnect {"mode":"live","room_id":12345}`。
> `room_id` 为空或非法会被拒绝（`mode=live` 必须有房间号）。

## 3. 点歌指令

观众在直播间（或控制台模拟弹幕）发送：

| 指令 | 说明 | 示例 |
|---|---|---|
| `点歌 歌名` | 搜歌并入队（前缀可配：`点歌/求歌/来首/我想听`） | `点歌 海阔天空` |
| `点歌 <源> 歌名` | 指定音源 | `点歌 qq 七里香`、`点歌 b站 晴天`、`点歌 网易云 晴天` |
| `切歌` / `下一首` / `skip` | 切歌（默认仅主播；开 `allow_user_skip` 后观众可切） | |
| `点歌列表` / `队列` | 查看当前队列 | |
| `点歌帮助` | 查看帮助文案 | |

源别名：`b站/bilibili/哔哩`、`qq/qq音乐/q音`、`酷狗/kugou`、`网易/网易云/netease`、

`本地/local`、`演示/demo/测试`。未启用的源会被拒绝并提示先去管理页打开。

**规则（可在控制台调整）**
- 同一用户点歌冷却 `user_cooldown_seconds`（默认 30s）
- 同一首歌重复点歌冷却 `song_cooldown_minutes`（默认 10min）
- 每人同时在队列上限 `max_per_user_queue`（默认 3）
- 队列总上限 `max_queue_length`、单首时长上限 `max_song_duration`、关键词黑名单 `blacklist`

## 4. 管理控制台功能

- **音源开关与排序**：勾选启用哪些源，拖动调整搜索优先级（未指定的源会智能按匹配度/播放量/收藏量排序选最优结果）。
- **扫码登录**：B站 / QQ / 酷狗 / 网易云 一键扫码，登录后播放付费/会员歌曲；Cookie 持久化，重启不丢失。
- **直播间**：切换 mock/live、设置房间号。
- **点歌规则**：冷却、队列上限、黑名单、是否允许观众切歌、是否保留播放列表等。
- **播放控制**：暂停/继续/拖动进度/切歌/置顶/调整顺序/移除。
- **热歌榜**：按点播次数自动统计 Top10。
- **模拟弹幕**：不连 B站也能完整测试全流程。

> 控制台所有修改只写入 `cache/settings.json`，**不会改动 `config.yaml`**；
> 点「恢复默认设置」即清空覆盖层回到 `config.yaml` 基线。

## 5. 本地音乐源

把音频放进 `./music/` 目录（`config.yaml` 的 `sources.local.music_dir` 可改），
文件名建议 `歌手 - 歌名.mp3`，同目录同名 `.lrc` 会自动作为歌词。

## 6. 测试

无框架脚本式测试，每个脚本独立运行（服务由脚本内子进程启动/停止，端口 **8788**）：

```bash
python tests/tests_regression_sources.py   # 6 源 search/resolve 回归（联网）
python tests/tests_edge_cases.py           # LRC/weapi/wav/local/网易云 边界（联网）
python tests/tests_login_qr.py             # 四平台二维码生成与轮询（联网）
python tests/tests_features_v4.py          # 设置/登录/切直播间/歌词/keep_state
python tests/tests_e2e.py                  # HTTP 全链路 + 重启持久化（离线 demo 源）
```

> 不要同时跑多个测试脚本（都占用 8788 端口）。详见 `tests/README.md`。

## 6.5 打包成单文件 exe（免装 Python 分享给别人）

已配好 PyInstaller，一条命令产出 `dist/bili-jukebox.exe`，**对方无需安装 Python**。

```bash
pip install pyinstaller
python -m PyInstaller build.spec --noconfirm   # 或双击 build.bat
```

产物 `dist/bili-jukebox.exe` 是单个文件，直接发给别人即可运行：

- 首次运行会在 **exe 同目录** 生成 `cache/`（`settings.json` 设置、播放列表都在这里，多次运行保留）；
- 建议把 exe 放到一个**有写入权限的普通文件夹**（如桌面、Downloads），不要放系统保护目录；
- 启动后控制台会打印三个页面地址；浏览器打开 `控制台` 即用。

> 资源打包说明：`web/` 与 `config.yaml` 由 `jukebox/config.py` 的 `_project_root()`
> 在运行时从 PyInstaller 解包目录（`sys._MEIPASS`）定位；可写缓存目录由 `app_data_dir()`
> 定位到 exe 同目录，保证设置持久化。

## 7. 配置说明（config.yaml）

- `server.port`：**硬性 8788**，不要改。
- `danmaku.mode`：`mock` / `live`。
- `jukebox`：点歌前缀、冷却、队列上限、黑名单、保留播放列表等。
- `sources.active`：启用的音源及优先级顺序。
- `cache.search_ttl_minutes`：搜索结果缓存时长。

## 8. 常见问题

- **双击 exe 后控制台一闪而过 / 自己关了**：
  - 已做两处保护：① 端口 8788 被占用时会**自动顺延到 8789/8790…**，不会再一启动就崩；
    ② 任何启动报错都会在黑窗口里**打印报错并提示「按 Enter 关闭」**，不会再无声消失。
  - 如果窗口里出现了红色报错，请把那段文字/截图发我。
  - 如果**完全没有任何窗口**（连一闪都没有），多半是 Windows 拦截了未签名的 exe：
    可右键 → 属性 → 解除锁定，或把 exe 加入杀软白名单后重试。
  - 若提示缺少运行库（极少），在联网环境下通常自动解决；仍可 `python run.py` 源码方式运行。
- **没声音 / 播放失败**：检查 OBS 播放页是否在前台、源是否联网、是否触发付费片段（看控制台提示）。
- **点歌搜不到**：换关键词（歌名/歌手），或换一个已启用的音源指定搜索。
- **live 模式收不到弹幕**：确认 `room_id` 正确、直播间正在直播、必要时填 `credential_file`。
- **想清空播放列表**：控制台清空队列 + 切歌；或关掉 `keep_state_on_exit` 后重启服务。
